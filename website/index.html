A desk, not a data pipeline

Everything an authoring environment should do — done on your disk, under your control.

✒

Real compiling, built in

A bundled Tectonic engine produces real PDFs out of the box — no TeX Live install, no toolchain setup. Optional system-TeX if you already have one.

🗂

144 multilingual templates

Nine document classes — article, beamer, letter, report, book, thesis, CV, homework, poster — each localized into all 16 languages with the correct preamble and fonts.

⇄

SyncTeX navigation

Click a line in the source, land on the PDF page. Click the preview, jump back to the source. Round-trip navigation that just works.

🕰

Local history

Project snapshots, diffs and restores — version your document without a git server or a subscription.

⌗

Fully scriptable

Every engine function is a command: warraqcraft-cli, a TCP control channel into a running GUI, and a JSON-RPC MCP server for agents.

🔒

Hostile-input safe

Clean-room Rust, shell escape permanently off, bounded parsing of untrusted .tex/.bib — documents can't touch your system.

Write in your language, not just English

Each template ships the right preamble for its script — polyglossia + XeLaTeX for Arabic-script languages, ctex for Chinese, xeCJK for Japanese, koTeX for Korean — with localized headings and sample text.

An AI harness you can inspect

Not a chatbot glued to an editor — a bounded, auditable system. Every task is durable, every edit is previewed and approved, every run is logged.

🛠

Bounded compile-repair

ai.repair.preview gathers structure and compile diagnostics into a minimal line-level plan; ai.repair.apply verifies anchors, patches, recompiles and records the outcome.

$ warraqcraft-cli cmd ai.repair.preview --file main.tex
🧭

Nothing hidden

Prompts, guardrails, skills and memory scopes are versioned and inspectable via ai.components. A permission matrix decides what each command may touch.

$ warraqcraft-cli cmd ai.components
✓

Deterministic evaluations

Six model-free fixtures — unclosed environments, nested strays, 500-deep hostile input — run in isolated workspaces and prove the repair path behaves.

$ warraqcraft-cli cmd ai.eval.run
🔌

Agent-ready

All 61 engine commands are reachable identically from the GUI, CLI, TCP control channel and the MCP server — plug your own tools in.

$ warraqcraft-cli mcp # JSON-RPC over stdio

WarraqCraft is a clean-room, open-source project — dual-licensed MIT / Apache-2.0. The name honours the warrāq (ورّاق), the medieval papermaker and stationer who kept the written word alive. Built in Rust; LaTeX-compatible; documents never leave your machine.
